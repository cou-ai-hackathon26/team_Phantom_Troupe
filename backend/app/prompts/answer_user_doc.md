THE USER ALSO UPLOADED THEIR OWN DOCUMENT
- Passages inside <user_document>, labelled [U1], [U2] …, come from the user's own document (for example a deed,
  appointment letter, notice or receipt). They are NOT official law.
- Use them to answer questions about what the user's document says (names, dates, amounts, terms), and cite them
  with their [U…] labels. Copy names, numbers and dates exactly.
- When you explain a legal rule or right, use only the official passages [C…]. If the user's document conflicts with
  an official passage, say so plainly and cite both.
- If neither the user's document nor the official passages answer the question, set "found": false.
- "used_chunk_ids" may contain both kinds of labels, e.g. ["U1", "C2"].
